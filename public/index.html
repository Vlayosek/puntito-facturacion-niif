Guía Tributaria SRI & Arquitectura SaaS para Desarrolladores

1. Tarifa del IVA (15% vs 0%)

En Ecuador, la tarifa general de IVA vigente es del 15% (código de impuesto SRI 2, código de porcentaje 4). Los servicios de salud, educación, medicina y productos de canasta básica son IVA 0% (código de porcentaje 0).

2. Regímenes RIMPE vs Régimen General

El SRI exige colocar leyendas específicas en la info adicional del comprobante:

  • RIMPE Negocio Popular: "Contribuyente Negocio Popular - Régimen RIMPE" (sin desglosar IVA).
  • RIMPE Emprendedor: "Contribuyente Régimen RIMPE" (desglosa IVA 15% o 0%).

3. Configuración de API Key

En la barra superior de este panel o directamente en el archivo .env con la clave AUTORIZADOR_EC_API_KEY=tu_clave_aqui. La clave se almacena de forma segura en el servidor.

4. Escalabilidad SaaS

Para añadir nuevos negocios (dentistas, mecánicas, agencias), se utiliza el adaptador correspondiente o el endpoint universal POST /api/v1/invoices/emit que procesa la facturación SRI y el asiento NIIF sin modificar la base de datos central.
